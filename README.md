# 🎵 BeatKSH

**Unity + FMOD 기반 2D 리듬게임 구현 프로젝트**

---

## 📌 프로젝트 개요

BeatKSH는 Unity와 FMOD를 기반으로 제작된 2D 리듬게임입니다.  
정밀한 판정 타이밍 구현을 위해 FMOD의 DSP Clock을 활용하고, Firebase를 통해 유저 인증 및 게임 기록 저장 기능을 연동하였습니다.  
또한, 채보를 직접 제작할 수 있는 Unity Editor 툴을 함께 개발하여 플레이어가 게임 콘텐츠를 자유롭게 생성할 수 있도록 설계되었습니다.

---

## 🎮 주요 기능

- 🎼 **FMOD 기반 정밀 오디오 타이밍 처리**
- 🕹️ **Perfect / Good / Miss 판정 시스템 및 키 입력 처리**
- 🛠️ **Unity Editor 내 채보 제작 툴**
- ☁️ **Firebase Authentication & Realtime Database 연동**
- 📁 **JSON 기반 채보 데이터 저장 및 로딩**
- 💫 **DOTween 기반 판정 UI 이펙트**
